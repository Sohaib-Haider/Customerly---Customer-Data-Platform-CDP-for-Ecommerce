# Future High-Value - CLV

## Dataset

Online Retail II

https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci

## Description

UK-based online retail transactions from Dec 2009 to Dec 2011. Company sells unique all-occasion gift-ware. Many customers are wholesalers. Contains all transactions including cancellations.

## Files & Attributes

online_retail_II.csv

- Invoice — Invoice number. Nominal. A 6-digit integral number uniquely assigned to each transaction. If this code starts with the letter 'c', it indicates a cancellation.
- StockCode — Product (item) code. Nominal. A 5-digit integral number uniquely assigned to each distinct product.
- Description — Product (item) name. Nominal.
- Quantity — The quantities of each product (item) per transaction. Numeric.
- InvoiceDate — Invoice date and time. Numeric. The day and time when a transaction was generated.
- Price — Unit price. Numeric. Product price per unit in sterling (£).
- Customer ID — Customer number. Nominal. A 5-digit integral number uniquely assigned to each customer.
- Country — Country name. Nominal. The name of the country where a customer resides.
